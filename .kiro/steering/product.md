# SchoolHub - School Management System

SchoolHub is a comprehensive web-based school management platform built for Indonesian educational institutions.

## Core Purpose

Manages all aspects of school operations including student information, teachers, staff, classes, schedules, academic content, exams, news, announcements, and student admissions (PPDB - Penerimaan Peserta Didik Baru).

## Key Features

- **User Management**: Multi-role authentication system (Admin, Guru/Teacher, Murid/Student, Karyawan/Staff, Calon Siswa/Prospective Student)
- **Academic Management**: Classes, subjects, schedules, materials, assignments, and grading
- **Exam System**: Regular exams and specialized PPDB admission exams with proctoring features
- **Content Publishing**: News articles and announcements with categorization and publication status
- **PPDB (Admissions)**: Online registration, exam administration, monitoring, and candidate management
- **Dashboard Analytics**: Role-based dashboards with statistics and reports

## User Roles

- **Admin**: Full system access, user management, system configuration
- **Guru (Teacher)**: Class management, content creation, grading, exam monitoring
- **Murid (Student)**: View assignments, take exams, submit work
- **Karyawan (Staff)**: Administrative support functions
- **Calon Siswa (Prospective Student)**: Registration and admission exam access

## Language

The application is built for Indonesian users with Indonesian language throughout the interface and database fields.
